# 기본 제공 요금표 출처

## 서울 · 중형 일반

- 출처: 서울시 공식 영문 교통 안내 https://english.seoul.go.kr/policy/transportation/modes-of-transport/
- 표의 적용 기준: 2023-02-01 04:00
- 확인일: 2026-11-14
- 버전: seoul-sedan-2023-02-01-v1
- 기본 4,800원 / 1.6km. 131m당 100원, 15.72km/h 미만에서 30초당 100원 거리/시간 부분 병산.
- 심야 22~23시 20%, 23~02시 40%, 02~04시 20%. 표기 기본요금은 각각 5,800/6,700/5,800원.
- 시외 20%, 심야+시외 합산 최대 60%. 최종 미터 금액 10원 단위 반올림.

기본요금 심야 표기와 일치하도록 기본요금 할증은 100원 단위 반올림, 추가요금은 10원 단위를 사용한다. 앱은 위치 기반 재미용 근사 계산이며 공식 계량기 구현을 보장하지 않는다. 상세 계량 방식이 필요한 경우 별도 고시를 확인해야 한다. 공식 안내에 기재된 시행 기준을 표시하며 이후 변경이 없다고 추정하지 않는다.

첫 버전은 서울 중형 일반과 직접 설정만 제공한다. 부산 등 출처 검증 전 지역은 임의 요금으로 등록하지 않는다. 직접 설정은 사용자 입력임을 구분하고 요금제 전체를 운행별 스냅샷으로 보관한다.
