# 기능 명세

## 목적

카풀할 때 켜두는 재미용 택시미터 스타일 앱. 결제·정산 기능 없음. Pleos Connect 가로 화면 우선.

## 미터

- 현재 금액을 가장 크게 표시. 불필요한 소개/홍보 문구 제외.
- 작은 게이지와 다음 증액분의 누적 금액 표시. % 또는 단위 기호 없이 숫자만 사용.
- 예: 게이지 64%일 때 100원 단위는 64, 200원 단위는 128. 증액 시 총액에 반영하고 0으로 초기화.
- 속도, 거리, 경과 시간 표시. 일시정지/재개, 종료.
- 말·고양이·토끼·오리의 단색 픽셀 애니메이션. 테두리 장식은 사용하지 않음.
- 정차 중에도 캐릭터는 느리게 달리며, 추정 속도에 따라 재생 속도 증가.
- 주야간 테마는 차량(시스템) 모드를 그대로 따른다. 앱에 수동 화면 모드는 없다. 야간은 어두운 배경/흰 캐릭터, 주간은 밝은 배경/검정 캐릭터.
- 운행 종료 확인과 오류 안내는 시스템 팝업이 아니라 앱 화면 안에서 보여준다(시스템 팝업은 전체 화면 기준이라 반쪽 패널에서 버튼이 잘림).
- 시외할증 켜기/끄기 버튼 하나. 시외할증은 이 버튼으로만 적용하며 자동 판정은 없음. 새 운행은 꺼진 상태로 시작.
- 메인 화면은 주행 중에도 사용 가능(`distractionOptimized`). 설정·주행 내역은 시스템이 주행 중 차단하므로 P 기어에서만 버튼을 켠다(기어는 Pleos Vehicle SDK `Gear`, 읽을 수 없으면 켜 둠). 주행 중 눌러 미터가 가려지면 앱이 화면에서 벗어나 운행이 일시정지되기 때문.

## 설정

- 지역 요금제 선택. 기본값은 서울 중형 일반. 부산·대구·대전·인천·광주·울산·세종 중형 일반 요금표를 기본 제공하며 출처·적용일·버전 관리. 확인되지 않은 항목은 설정 화면에 표시(docs/tariff-sources.md). 그 외 지역은 직접 설정 지원.
- 직접 설정: 기본요금/기본거리, 추가요금/거리 단위, 저속 시간 단위 및 기준 속도.
- 심야할증 사용 여부와 복수의 시간 구간/할증률 편집. 자정을 넘는 시간대 지원, 중복 구간 검증.
- 시외할증률과 심야/시외 중복 적용 방식 편집.
- 캐릭터 설정. 화면 모드(주간/야간) 설정은 없음(차량 모드를 따름).
- 별도 저장 버튼 없음. "미터로 돌아가기" 또는 뒤로가기로 저장하며 입력값이 잘못되면 저장하지 않고 안내.

## 할증

- 심야: 요금제의 지역 시각과 시간 구간으로 자동 적용. 화면의 야간 모드와 독립.
- 시외: 완전 수동. 메인 버튼으로 적용 여부를 전환하며 자동 감지(NaviHelper 주소, 행정구역 비교)는 제거함. 이유는 docs/surcharge-behavior.md.
- 요금 규칙 변경은 이후 누적분에 적용. 이전 금액 소급 변경 없음.
- 지역별 할증률·시간대는 요금표에 따르며 실제 택시 사업구역의 예외는 반영하지 않음.

## 속도·거리

- 위치(GPS/FusedLocation) 기반 입력은 사용하지 않는다.
- 속도: AAOS `PERF_VEHICLE_SPEED`를 `android.car.Car`/`CarPropertyManager`로 읽는다. `android.car.permission.CAR_SPEED`(dangerous, 런타임 허용. 허용 창 문구는 "위치 정보")가 필요하며 에뮬레이터에서 약 6.6Hz로 갱신된다. `useLibrary 'android.car'`와 `<uses-library android:name="android.car" android:required="false"/>` 필요.
- 거리: 속도(m/s)를 시간으로 적분(사다리꼴)해 1초마다 요금 엔진에 전달한다. 3초 넘는 공백은 잇지 않고 정차로 취급하지 않는다(요금 누적 보류).
- 대체 입력: 속도 권한이 없거나 5초 안에 속도가 오지 않으면 Pleos Vehicle SDK 오도미터(`PERF_ODOMETER`, km 단위 float, `CAR_DRIVE`)를 1초마다 읽어 증가분을 거리로, 최근 10초 평균을 속도로 쓴다. 값이 그대로면 정차, 응답이 없으면 알 수 없음(보류)으로 취급한다. 실차의 정밀도·갱신 주기는 미확인. `android.car`로 오도미터를 읽는 것은 `CAR_MILEAGE`(signature|privileged) 때문에 불가능.
- 속도와 오도미터는 동시에 쓰지 않아 요금이 이중으로 쌓이지 않는다.
- NaN·무한대·음수 속도/오도미터 값은 건너뛴다(적분기와 요금 엔진 모두). 오도미터가 거꾸로 가면 초기화로 보고 요금에 넣지 않는다. 범위 상한·급증 같은 비정상 판정은 두지 않는다. 요금 엔진은 수신 끊김과 10초 초과 공백도 보류한다.
- 속도 권한은 첫 실행 때 한 번 요청한다. 메인 화면에는 수신 상태 줄과 권한 재요청 버튼을 두지 않는다.
- 누적 오도미터가 크면 float 정밀도가 약 4~8m로 거칠어진다(32,768km 이상).
- SDK 의존성 다운로드/컴파일과 실제 서비스 데이터 수신을 구분해 검증.

## 주행 내역

- 운행 시작/종료 시각, 거리, 소요 시간, 최종 금액, 지역과 요금제 버전.
- 심야/시외할증 적용 구간과 변경 기록.
- 기기 내 저장을 우선하며, 첫 버전에서 경로 좌표 전체 저장은 필수 아님.

## 미리보기와 구현 경계

HTML은 동작 탐색용 초안이며 요금/주행 내역은 예시다. 현재 Android APK에는 요금 엔진·설정·미터·캐릭터·주행 내역·차량 속도/오도미터 입력이 구현되었다. 빌드와 자동 테스트를 통과했고 Pleos Connect Emulator v2.1.0에서 실행을 확인했지만 실차 수신/실행은 별도 검증이 필요하다. 앱이 화면에서 벗어나면 운행을 일시정지하고 복귀 후 직접 재개한다.
