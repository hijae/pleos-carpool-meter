# 기능 명세

## 목적

카풀할 때 켜두는 재미용 택시미터 스타일 앱. 결제·정산 기능 없음. Pleos Connect 가로 화면 우선.

## 미터

- 현재 금액을 가장 크게 표시. 불필요한 소개/홍보 문구 제외.
- 작은 게이지와 다음 증액분의 누적 금액 표시. % 또는 단위 기호 없이 숫자만 사용.
- 예: 게이지 64%일 때 100원 단위는 64, 200원 단위는 128. 증액 시 총액에 반영하고 0으로 초기화.
- 속도, 거리, 경과 시간 표시. 일시정지/재개, 종료.
- 은은한 LED 테두리. 말·고양이·토끼·오리의 단색 픽셀 애니메이션.
- 정차 중에도 캐릭터는 느리게 달리며, 추정 속도에 따라 재생 속도 증가.
- 차량 시스템의 주야간 테마 연동. 야간은 검정 배경/흰 캐릭터, 주간은 밝은 배경/검정 캐릭터.
- 시외할증 켜기/끄기 버튼 하나. 상태는 자동 또는 수동으로만 표시.
- 메인 버튼을 조작하면 설정도 수동 모드로 전환. 자동 재선택은 설정에서만 제공.

## 설정

- 지역 요금제 선택. 기본 제공 요금은 출처·적용일·버전 관리. 서울 중형 일반을 공식 안내 기준으로 제공하고 나머지는 직접 설정 지원.
- 직접 설정: 기본요금/기본거리, 추가요금/거리 단위, 저속 시간 단위 및 기준 속도.
- 심야할증 사용 여부와 복수의 시간 구간/할증률 편집. 자정을 넘는 시간대 지원, 중복 구간 검증.
- 시외할증률과 심야/시외 중복 적용 방식 편집.
- 행정구역 변경 시 시외할증 자동 적용 ON/OFF.
- 캐릭터, 차량 주야간 연동 설정.

## 할증

- 심야: 요금제의 지역 시각과 시간 구간으로 자동 적용. 화면의 야간 모드와 독립.
- 시외 자동: 출발 시 행정구역을 고정하고 이탈 시 적용, 복귀 시 해제.
- 시외 판단은 같은 행정구역 단계의 코드로 비교. 시·군 기준에서는 같은 시 안의 구 변경을 무시.
- 시외 자동 감지 소스는 NaviHelper.getCurrentLocationInfo를 우선 조사. 실제 AAR 응답에는 행정구역 코드가 없고 주소 문자열이 있다. 주소를 시도/시군 이름 키로 정규화하고 불명확하면 자동 판정을 보류한다. 별도 역지오코딩/경계 공급자는 아직 연동하지 않는다.
- 자동 감지에 지연/안정화 적용. 수신 끊김을 구역 이탈로 취급하지 않음.
- 수동 전환 시 현재 시외 적용 상태를 보존하고, 버튼은 적용 여부를 전환.
- 요금 규칙 변경은 이후 누적분에 적용. 이전 금액 소급 변경 없음.
- 행정구역 기반의 재미용 규칙이며 실제 택시 사업구역의 모든 예외를 보장하지 않음.

## 위치·거리·속도

- 재미용 목적에 맞게 FusedLocation 기반 추정 속도로 시작. AAOS PERF_VEHICLE_SPEED는 초기 범위에서 제외.
- FusedLocation 1.1.3의 좌표·시각·신뢰도 활용. 실제 SDK에 속도 필드 없음.
- isSupported 확인, FUSED_LOCATION 위험 권한 처리, 업데이트 구독/해제.
- 좌표 변화로 속도 추정 및 평활화. 정차 흔들림, 저신뢰도, 오래된 값, 수신 누락 처리.
- Vehicle Odometer 거리 차분은 갱신 주기·단위 확인 후 활용 여부 결정.
- SDK 의존성 다운로드/컴파일과 실제 서비스 데이터 수신을 구분해 검증.

## 주행 내역

- 운행 시작/종료 시각, 거리, 소요 시간, 최종 금액, 지역과 요금제 버전.
- 심야/시외할증 적용 구간과 자동/수동 변경 기록.
- 기기 내 저장을 우선하며, 첫 버전에서 경로 좌표 전체 저장은 필수 아님.

## 미리보기와 구현 경계

HTML은 동작 탐색용 초안이며 요금/주행 내역은 예시다. 현재 Android APK에는 요금 엔진·설정·미터·캐릭터·주행 내역·위치/주소 SDK 연결이 구현되었다. 빌드와 자동 테스트를 통과했지만 실제 Pleos 서비스 수신/실행은 별도 검증이 필요하다. 앱이 화면에서 벗어나면 운행을 일시정지하고 복귀 후 직접 재개한다.
